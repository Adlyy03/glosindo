Bantu saya membuat dan mengintegrasikan **Swagger / OpenAPI documentation** untuk project backend ini.

### Konteks Project

* Backend: **Laravel Lumen**
* Authentication: **JWT**
* Database: **MySQL**
* Project: **GLOSINDO Guestbook API**
* Swagger UI harus bisa dibuka melalui browser, misalnya:
  `http://api-guestbook.test/swagger/`

### ATURAN PENTING

Jangan langsung membuat dokumentasi berdasarkan asumsi.

**Pertama, lakukan analisis terhadap source code project terlebih dahulu.**

Periksa:

1. `routes/`
2. `app/Http/Controllers/`
3. `app/Models/`
4. `app/Http/Middleware/`
5. `database/migrations/`
6. `database/seeders/`
7. `.env.example`
8. `bootstrap/app.php`
9. `composer.json`
10. konfigurasi JWT yang sudah digunakan project

Identifikasi seluruh endpoint API yang benar-benar ada di source code.

### Yang Harus Dibuat

Buat dokumentasi **OpenAPI 3.x** yang lengkap berdasarkan endpoint aktual project.

Dokumentasikan setiap endpoint dengan:

* HTTP method
* URL/path
* summary
* description
* request parameters
* request body
* content type
* required/optional fields
* validation rules
* response success
* response error
* HTTP status code
* authentication requirement
* JWT Bearer authentication jika endpoint membutuhkan login

### JWT Authentication

Tambahkan security scheme:

```yaml
components:
  securitySchemes:
    bearerAuth:
      type: http
      scheme: bearer
      bearerFormat: JWT
```

Endpoint yang membutuhkan JWT harus menggunakan:

```yaml
security:
  - bearerAuth: []
```

Pastikan Swagger UI menyediakan tombol **Authorize** agar JWT dapat dimasukkan dan digunakan untuk testing endpoint protected.

### Struktur Dokumentasi

Gunakan struktur seperti:

```text
docs/
└── openapi.yaml

public/
└── swagger/
    └── index.html
```

Jika struktur project membutuhkan pendekatan berbeda, gunakan struktur yang paling sesuai dengan Lumen tanpa merusak project yang sudah ada.

### Swagger UI

Integrasikan Swagger UI agar dapat diakses melalui:

```text
/swagger/
```

Contoh:

```text
http://api-guestbook.test/swagger/
```

Swagger UI harus membaca:

```text
/docs/openapi.yaml
```

atau path relatif yang benar sesuai struktur project.

### Hal yang WAJIB diperhatikan

1. Jangan mengubah behavior endpoint yang sudah ada.
2. Jangan menghapus route existing.
3. Jangan mengubah database schema kecuali benar-benar diperlukan.
4. Jangan membuat endpoint fiktif.
5. Jangan mengarang request/response.
6. Gunakan field dan validation yang benar-benar ditemukan di source code.
7. Sesuaikan dokumentasi dengan response JSON aktual dari controller.
8. Pastikan path OpenAPI benar sehingga Swagger UI tidak mengalami:
   `Fetch error: Not Found`
9. Pastikan konfigurasi Lumen tetap kompatibel.
10. Jangan menggunakan command Laravel yang tidak tersedia di Lumen.
11. Jika membutuhkan package tambahan, jelaskan package tersebut dan alasannya sebelum mengubah `composer.json`.

### Setelah Implementasi

Lakukan testing:

1. Pastikan aplikasi dapat boot tanpa error.
2. Pastikan semua route existing masih tersedia.
3. Pastikan Swagger UI dapat dibuka.
4. Pastikan `openapi.yaml` berhasil dibaca Swagger UI.
5. Pastikan tombol **Authorize** bekerja untuk JWT.
6. Test beberapa endpoint langsung melalui Swagger UI.
7. Pastikan request dan response yang ditampilkan sesuai implementasi sebenarnya.

3. Dependency yang ditambahkan, jika ada.
